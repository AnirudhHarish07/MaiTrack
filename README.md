# MaiTrack

Notes, helper scripts and the daily Routine prompt for the Asia-region CRO vendor scorecard (PK / ADA / toxicology).

The data itself lives in the Google Sheet "CRO Vendor Scorecard" (id `1J7G3_EVmlChUVFQJCAzMfmU5rHBEiODX0rNT9L81vQU`), not in this repo. No scraped vendor data or contact details are stored here.

- `docs/workflow.md` - sheet layout, order of work, scoring rules, Sheets write hazards
- `docs/rubric.md` - the 17-criterion rubric and tier bands
- `briefs/` - instructions used for helper agents (scoring, gap-fill, contact details)
- `scripts/` - merge scripts from the original run (reference; they assume the original working-folder layout)
- `routine/daily_cro_routine_prompt.md` - prompt for the daily Routine that adds 20-25 new CROs
